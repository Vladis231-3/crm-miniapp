# Atmosfera — аудит и отчёт о редизайне

## Обнаруженный стек

- React 18 + TypeScript/TSX
- Vite 6 и Tailwind CSS 4
- Radix UI / MUI primitives
- Lucide Icons
- Framer Motion
- Recharts
- React Hook Form
- npm (`package-lock.json`)

Точка входа: `src/main.tsx` → `src/app/App.tsx` → `AppProvider`.
Сетевой слой: `src/app/api.ts`. Состояние и операции: `src/app/context/AppContext.tsx`.
Telegram Mini App: `useTelegramMainButton`, `useTelegramBackButton`, `colorScheme`, `themeParams`, `ready`, `expand`.

## Карта ролей и экранов

### Клиент

Каталог услуг, поиск и категории; карточка услуги; выбор параметров, даты и времени; подтверждение; активные и прошлые записи; отмена; уведомления; профиль и автомобили.

### Мастер

Сегодняшние задачи; текущая работа; расписание; календарь загрузки; поиск автомобилей; детализация заказа; запуск/завершение задачи; дополнительные услуги; чек-лист смены; доход и зарплатная детализация; удержания; история; профиль, уведомления, безопасность и привязка Telegram.

### Администратор

Календарь и контроль записей; новая запись; статусы и назначение мастеров; клиенты и карточки; статистика; склад, категории и списания; смены; зарплаты; сотрудники; расписание, боксы и услуги; уведомления; интеграции и настройки.

### Владелец / бухгалтер

Операционный дашборд; календарь; доходы, расходы и прибыль; зарплаты мастеров и владельцев; выплаты; склад; отчёты и экспорт; копилка; депозиты; клиенты; архивы; смены; контент; интеграции, безопасность и системные настройки.

## Сохранённые функции

- API-адреса, методы, payload и авторизация не изменены.
- `AppContext`, расчёты, модели, статусы и права ролей не изменены.
- Telegram Main/Back Button и тема Telegram сохранены.
- Маршруты, обработчики, формы, валидация, даты, расписание и зарплаты сохранены.
- Загрузки, ошибки, пустые состояния, уведомления, модальные окна и экспорт сохранены.
- Реальные данные не заменялись моками. Локальные данные применялись только во внешнем smoke-harness для визуального QA и не входят в проект.

## Design Read

Спокойный монохромный fintech для сервисного бизнеса: графитовые поверхности, тёплые нейтрали и один дозированный лаймово-оливковый акцент Atmosfera. Акцент обозначает главный CTA, выбранное состояние и ключевой показатель. Визуальный слой использует границы вместо тяжёлых теней, функциональные карточки вместо одинакового bento-grid и Lucide как единую систему иконок.

## Что изменено

- Добавлен единый слой `src/styles/atmosfera-redesign.css`.
- Обновлены светлые и тёмные визуальные токены во всех ролевых приложениях.
- Унифицированы заголовки, поверхности, KPI, карточки, поля, кнопки, статусы, таблицы, модальные окна и нижняя навигация.
- Клиентский CTA «Записаться» получил максимальный визуальный приоритет.
- Для мастера усилена иерархия «текущая работа → следующая задача → список».
- Для администратора и владельца финансовые и операционные данные переведены в компактную мобильную структуру.
- Англоязычные служебные подписи в новых операционных блоках заменены русскими.
- Добавлены `aria-current`, `aria-label`, видимые focus-состояния, touch-target 44 px, reduced motion и high-contrast overrides.
- Добавлена адаптация для 320 px и Telegram Desktop; горизонтальный page-scroll исключён.

## Проверки

- Проверочный production bundle собран через esbuild: JS успешно разобран `node --check`, CSS прошёл проверку структуры.
- Визуальный QA выполнен в Chromium на 320, 390 и 430 px для клиента, мастера, администратора и владельца в обеих темах.
- Runtime-исключений и console errors в проверенных состояниях нет.
- API, AppContext, Telegram hooks, валидация, даты и расчёты сверены с исходным архивом — содержимое идентично после нормализации переводов строк.
- Контраст ключевых пар проверен по WCAG.
- В `package.json` отсутствуют отдельные scripts для lint/test.

## Особенность исходного архива

Архив содержал `node_modules` с Windows optional packages Rollup. Поэтому `npm run build` в Linux sandbox не может загрузить `@rollup/rollup-linux-x64-gnu`. Это не ошибка исходного кода. Итоговый ZIP не содержит `node_modules`: после распаковки выполните `npm ci`, затем `npm run build` — npm установит нативный пакет текущей платформы.
